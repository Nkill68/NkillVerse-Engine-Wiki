Sprites and animations

Creating, adding, and managing sprites in a Custom Lua State.

makeLuaSprite(tag, image, x, y)
Creates a sprite and registers it with a tag.

Create a sprite using the assets in the current state. First, search for a Sparrow atlas, and if it's not available, try loading a regular image. Creating a sprite doesn't automatically add it to the state.

Syntax

makeLuaSprite(tag, image, x = 0, y = 0)

Parameters

ParameterTypeDescription
tagstringUnique identifier of the sprite.
imagestringAsset name/path relative to states_assets/<stateName>/.
x, ynumberInitial position, default 0.

Example

makeLuaSprite("logo", "logo", 320, 180)
addLuaSprite("logo")
addLuaSprite(tag)
Adds a previously created sprite to the state.

Adds the registered sprite with the specified tag to the scene. Tags ending with -Hookare ignored.

Syntax

addLuaSprite(tag)

Parameters

ParameterTypeDescription
tagstringTag of the previously created sprite.

Example

makeLuaSprite("background", "bg", 0, 0)
addLuaSprite("background")
removeLuaSprite(tag)
Removes and destroys a registered sprite.

Removes the sprite from the state and clears the associated tag. Tags with suffixes -Hookare ignored.

Syntax

removeLuaSprite(tag)

Example

removeLuaSprite("logo")

Parameters

ParameterTypeDescription

fpsnumberFrame rate in frames per second, default 24.
loopedbooleanIf the animation needs to repeat.
flipx, flipybooleanFlips the animation on the X/Y axes.

Example

3D objects and meshes

Primitives, hierarchy, mesh and transformations of three-dimensional objects.

add_obj(tag, type, x, y, z, sx, sy, sz)
Create a 3D primitive or group.

The internal implementation of the primitives is provided by Primitives: plane, quad, cube, sphere, cylinder, coneand . The and torustypes depend on the wrapper. Tag handling and Lua callback names are not defined by the Haxe classes described.emptygroup

Wrapper syntax

add_obj(tag, type, x = 0, y = 0, z = 0, sx = 1, sy = 1, sz = 1)

Internal primitive parameters

PrimitiveParametersDescription
planew=1, d=1, segX=1, segZ=1Divisible plan.
quadw=1, h=1Quadrilateral.
cubesx=1, sy=1, sz=1Cube or parallelepiped.
sphereradius=1, segments=32, rings=16Sphere with radius and subdivisions.
cylinderradiusTop=.5, radiusBottom=.5, height=1, segments=32, capTop=true, capBottom=trueCylinder with configurable ends.
coneradius=.5, height=1, segments=32Cone obtained from a cylinder with zero upper radius.
torusR=1, r=.3, segments=32, tube=16Torus with major radius R and tube radius r.

The primitives use counterclockwise winding for the front face and the positive Y-axis as the upward direction.

Example

add_obj("myCube", "cube", 0, 0, 0, 1, 1, 1)

Loading OBJ, glTF, and GLB models is not directly defined by the 15 basic Haxe classes listed here. Supported formats, material handling, child naming, and return values ​​must be verified in the actual loader and wrapper.

remove_obj(tag)
Removes an object from the scene.
remove_obj(tag)

Object3Dsupports hierarchy with addChild()and removeChild(). Recursive removal and release of resources depends on the wrapper.

has_obj(tag) / get_obj(tag)

These are declared signatures for hscript not lua

clear_objects() / clear_scene()
Clear the scene objects.
clear_objects() clear_scene()

The hierarchy Object3Dallows you to remove children from the root. Whether tags, lights, and reflectors are cleaned up depends on the wrapper.

Mesh3D: fromArrays / computeNormals / computeTangents
Builds and prepares geometry.
fromArrays(pos, nrm?, uv?, idx) computeBounds() computeNormals() computeTangents() upload() ensureUploaded() markDirty() draw() dispose() splitLarge()

posContains flattened XYZ coordinates. Normals, UVs, RGBA colors, and tangents are optional. During upload, implementation-predicted missing data is computed; missing UVs are set to zero, and missing vertex colors are set to white.

The interleaved buffer uses 16 floats per vertex: position 3, normal 3, UV 2, color 4, and tangent 4. The indices are 16-bit: for meshes beyond the useful limit of about 65,000 vertices, use splitLarge(). After runtime changes to positions or indices, call markDirty().
